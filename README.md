# 四个音，一整个世界

面向不识谱者的贝多芬《第五交响曲》第一乐章交互教学工具。先听见现象，再看结构，再揭示名称。

## 打开

**直接用浏览器打开 `index.html`，或在 macOS 双击 `打开教学工具.command`。** 不需要安装依赖、登录账号或联网。首次点击播放后才会启用声音。

也可以在此目录运行：

```sh
python3 -m http.server 8877 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8877>。端口已占用时换一个数字。

## 建议的第一趟：10–15 分钟

1. **认识四个音**：正常听一次，再用 40% 速度听。点音符试音、循环，找出最后一个音向下落。听过后揭示“动机”的名称。
2. **让它变一变**：先试“换音高”和“只留下节奏”，再试“前后互相追逐”。点击“原版 → 变化版”，听被保留的关系。绿色/橙色/蓝色与文字共同解释变化。
3. **听见整座建筑**：点击第 63 小节的快捷入口。单听弦乐再恢复全部；把舒展旋律与低处的节奏联系起来。再听第 268 小节的双簧管独白、第 374 小节的延迟结束。
4. **积木工作台**：跟随整曲看结构模型；或排出自己的 A、B、C、D 组合。试着比较 `A A B D` 和 `B A D A`。拼接顺序是你的实验，不是原作。
5. 最后完整听一遍。可以调到 0.75×，可在任意位置跳转，也可以循环当前地图区域。空间键控制全曲播放/暂停（输入框和按钮获得焦点时保留原有键盘行为）。

顶部导听卡和底部播放器均显示当前位置。时间按 **1× 时间标尺** 显示，变速不会改变作品坐标。切到其他教学页不暂停全曲；开始播放任何小实验会暂停全曲，避免两套声音重叠。切换到其他浏览器标签/后台时暂停，回来后手动继续。

- 原版、换音高、换音色、改变强弱、删去片段、节奏抽象、声部叠合、错位接力，分别试听和顺序对比。

- 7 格播放地图对应 5 个直觉阶段（最初两区域分别反复），可按需揭示传统名称。
- 音频时钟驱动的动态钢琴卷帘、实时声部名单、同音短击模式提示、18 段人工导听、来源回听与地图关联标记。
- 弦乐、木管、铜管、定音鼓分组开关和单听；音量、变速、暂停、拖动、段落循环。
- 积木跟随视图与最多 12 块的组合沙盒；支持增删、撤回与播放。
- 无运行时网络请求、无 CDN、无框架依赖；桌面与手机响应式排版、键盘按钮操作及减少动态效果设置。

## 音乐与教学边界

这是**原谱音符的合成导听，不是交响乐团录音**。声音使用 Web Audio 合成，方便同时发声、变速和拆分声部。

- 音高、时值、轨道来自 Mutopia 的 MIDI；原文件没有展开呈示部反复，本工具把前 248 个四分音符拍复制一次。
- MIDI 中所有力度值都是 90；对应 LilyPond 总谱移除了 `Dynamic_performer`。因此全曲不恢复真实的强弱表情。“改变强弱”教学实验是另外明确生成的示范。
- 原文件不演绎指挥的自由速度、延长记号停顿。其基准为每分钟 192 个四分音符；含反复的导听约 **6 分 34 秒**，不能拿这个时间去对齐别的录音。
- 双簧管自由段对应原谱第 268 小节，但在 MIDI 时间里占 12 个四分音符拍。第 269 小节及之后的映射已扣除额外 10 拍；最后的第 502 小节起于原 MIDI 第 1012 拍。
- 声部名称依据总谱的 12 个 staff 顺序，而非盲信 GM program：源文件圆号与小号都设成了 English horn，界面按总谱识别为铜管。
- “正在发生”是段落级人工解释；实时声部列表由当前实际播放的音符生成。三短一长检测只是固定节奏形态匹配，不代表自动认定所有贝多芬动机，也会漏掉和弦内声部、变形节奏等情形。
- A 是四音种子，B 指对比区域的歌唱，C 是连接推进的段落角色，D 是 A 的节奏抽象。它们并非四个独立主题，也不能解释每一个音。双簧管独奏单独标识，不归为第二主题 B。
- 沙盒 B 取第一小提琴第 63–66 小节，C 取第 34–37 小节；A / D 及变化按钮为教学实验。沙盒使用统一慢一些的速度，重新拼接后的音乐不属于贝多芬原作。
- 每个可视化长方块表示一个源 MIDI 音符事件；连音线合并成一个较长事件。合成包络为了避免点击噪声有很短的起音与释音，视觉按谱面时值标注。

## 来源与许可

1. **乐谱、MIDI 与 LilyPond 源码：** [Mutopia Project, Symphony No. 5 – Op. 67, 1st Movement](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=941)，标识 `Mutopia-2017/11/05-941`。原版来源 Breitkopf and Härtel (1862–1865)。录入 Stelios Samelis，Johannes Heinecke 适配。页面标明 Public Domain，可分发、修改和演奏。对应文件完整保存在 `assets/`，未改写原下载文件。
2. **大结构与小节边界：** [William Wieland, Beethoven 5 / Big Picture](https://williamwieland.com/theory/mus715/Beethoven_5/BigPic.pdf)。呈示 1–124、展开 125–247、再现 248–373、尾声 374–502；对比区域含第 59 小节呼唤，第 63 小节开始弦乐歌唱。边界是该分析采用的划分，其他分析在过渡/结束主题的命名上可以不同。
3. **核对日期：** 2026-09-19。通过用户指定的本地 Firecrawl 检索，未使用 Firecrawl Cloud。检索证据保存在 `.firecrawl/`。

## 开发与核查

- `index.html`：中文内容和四个学习界面。
- `style.css`：自适应界面样式。
- `app.js`：Web Audio 合成器、音频时钟、播放状态、分段注释与实验。
- `score-data.js`：可离线使用的音符数据。
- `scripts/build_score.py`：仅使用 Python 标准库重新解析原始 MIDI。
- `scripts/verify-browser.cjs`：Playwright 浏览器检查。
- `verification.json`：本机检查结果；`preview-*.png`：界面截图。

重建数据：`python3 scripts/build_score.py`。运行测试：`node scripts/verify-browser.cjs`。测试脚本默认使用此机器的捆绑 Playwright；其他机器可设置 `PLAYWRIGHT_MODULE` 为安装好的 Playwright 包路径。

已验证实际 PCM 非零、八种试听、播放高亮、暂停静音、变速、跳转、循环边界、声部单听、沙盒编辑、结尾停止、390px 各页无横向溢出，以及 Chromium 无运行异常；以 `verification.json` 为准。这些是实现自检，**不等同于音乐教师独立审校，也没有证明真实扬声器音质或 Safari/iOS 全版本兼容**。
